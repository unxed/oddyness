## Как читать утверждения

- **Факт источника** — что написано в официальном документе либо обнаружено в
  конкретном исходнике. Ссылка/путь рядом; это не гарантия полного покрытия.
- **Вывод исследования** — наша оценка применимости. Её можно оспорить новым опытом.
- **Кандидат** — найденная возможность, ещё не принятая зависимость.
- **Пробел** — неизвестное или непроверенное. Не заполняем догадкой.

README стороннего проекта подтверждает его заявления, а не их истинность.
Грамматика не определяет всю семантику, прохождение тестов одного рантайма не
доказывает совместимость с 1С, открытая видимость файлов не определяет права на
их включение. Архитектурные статьи об оригинале описывают оригинал, а не
обязательный способ реализации oddyness.

Собственные формулировки досье не являются копией руководств. В репозиторий не
включены чужие исходники, справка, схемы, конфигурации или дистрибутивы.
