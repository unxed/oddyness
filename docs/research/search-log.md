# Методика и журнал охвата

Исследование выполнено **2026-10-21**. Исходная база oddyness:
`ca4c8257748b160d61eb87296104c069ad9d6400` (единственный файл LICENSE,
BSD-3-Clause). Исходники сторонних проектов не добавлены в oddyness.

## Методика

1. Открыты все отправные ссылки инициатора. Для недоступных поисковому сервису
   GitHub-страниц использованы прямой GitHub API и git clone.
2. Поиск в двух поисковых системах: сначала широкое обнаружение, затем уточнение
   первичных официальных источников и конкретных репозиториев.
3. На GitHub прочитаны описание, ветка, HEAD, README и доступный текст лицензии.
   Для ключевых Go-компонентов дополнительно просмотрены отдельные исходники.
4. Для 17 веб-адресов сделаны прямые HTTP-запросы с фиксацией URL результата,
   статуса, размера и SHA-256 HTML. Из них один оказался soft-404.
5. По публичным страницам/исходникам сформированы собственные описания и
   исследовательские вопросы. Полные страницы/руководства в patch не включены.
6. Результаты оригинала, сравнения совместимости и бенчмарки не имитировались.

## Глубина осмотра

[repositories.json](repositories.json) содержит 36 записей с ролями: для 32 зафиксирована ревизия,
для четырёх получены только метаданные. Пути прочитанных файлов и их хеши
приведены там, где удалось получить содержимое. Уровни осмотра определены в `03-reuse.md`. Для README, полученных через
API, хеш относится к декодированному содержимому; файлы clone хешировались как
байты checkout. Ветки могут двигаться; ссылки на HEAD фиксируют этот срез.
Время коммита не равнозначно времени релиза или показателю зрелости.

Дополнительно просмотрены публичные страницы:
[Vanessa Automation](https://github.com/Pr-Mex/vanessa-automation),
[onec_dtools](https://github.com/Infactum/onec_dtools),
[dt-demo-configuration](https://github.com/1C-Company/dt-demo-configuration),
[официальная статья о внутреннем устройстве](https://habr.com/ru/companies/1c/articles/269611/).
Для этих страниц без прямого файлового осмотра не заявляется кодовый аудит.

## Ограничения доступа и непроверенные направления

- Часть страниц GitHub не открывалась через поисковый fetch; git clone для
  oddyness и ключевых проектов работал. Это ограничение маршрута доступа,
  не основание считать репозиторий отсутствующим.
- После части запросов GitHub API стал возвращать HTTP 403. Некоторые README
  и лицензии добраны через git clone; у оставшихся кандидатов явно нет
  квалифицированной ревизии/лицензии. Причина всех 403 отдельно не установлена.
- Угадываемый адрес `.../practical_developer_guide/` вернул HTTP 200 с редиректом
  на `/404.php`; как источник содержания он **не использован**. Рабочие главы
  и каталог Tutorials приведены отдельно. HTTP 200 не равен успешному чтению.
- Не выполнялись вход в ИТС, регистрация, получение/активация лицензии,
  скачивание платформы и запуск защищённых материалов.
- В PATH нет `go`; сборки и бенчмарки не запускались. Предмет шага — документы.
- Статусы лицензий — инвентарь прочитанного текста, не аудит происхождения всего
  дерева и не разрешение на будущее включение.
