# Где брать сведения о 1С:Предприятии

## Надёжная основа для планирования

**Покупка коммерческой копии не является условием начала исследования.**
Есть публичные официальные материалы и бесплатные варианты доступа к продукту.
Однако в этой работе оригинал не устанавливался и поведенческие эксперименты
не проводились. Доступ к сайту не означает получение дистрибутива или лицензии.

| Класс | На что можно опереться | Чего источник не доказывает |
| --- | --- | --- |
| Официальное версионное руководство | Публичная модель и заявленная семантика конкретной версии | Отсутствие ошибок реализации, полноту всех граничных случаев |
| Воспроизводимый опыт на оригинале | Наблюдаемое поведение указанной сборки, клиента, ОС и режима | Универсальность для всех версий/режимов |
| Официальные примеры и XML-выгрузки | Форму данных и употребление механизмов | Полную спецификацию формата, право копировать все файлы |
| Независимые рантаймы и их тесты | Альтернативную формализацию, идеи опытов | Точное поведение 1С или полноту платформы |
| Открытые парсеры/анализаторы | Практический синтаксис, ошибки и распространённые конструкции | Семантику исполнения, транзакций и UI |
| Авторские статьи разработчиков 1С | Объяснение мотивов и исторического устройства | Современный ABI/протокол или требование повторить устройство |
| Wikipedia, каталоги, форумы, видео | Термины, направления поиска, пользовательские сценарии | Достаточную спецификацию для реализации |
| Ответы LLM/AI-индексы/MCP | Быстрый поиск и проектирование опытов | Самостоятельное свидетельство без первоисточника |

Для спорного требования нужны **версионный официальный источник и минимальный
контрпример на оригинале**. Пока опыта нет, так и помечаем. Воспроизводимый баг
может расходиться с документацией: хранить оба свидетельства, а решение о
совместимости с багом принимать отдельно.

## Как получить наблюдения оригинала без своей коммерческой копии

### Учебная версия

Официальные страницы:
[русская](https://v8.1c.ru/podderzhka-i-obuchenie/uchebnye-versii/),
[английская с ограничениями](https://1c-dn.com/developer_tools/1c_enterprise_8_platform_training_version/).

Это оригинальная платформа для обучения, а не независимый эмулятор.
Она подходит как потенциальный стенд для языка, маленьких метаданных и форм.
По англоязычной странице ограничены объёмы данных; отсутствуют клиент-серверный
режим и некоторые интеграции, есть ограничения печати и сохранения табличных
документов. Производительность ограничена: её нельзя брать за норму скорости
коммерческого продукта. Конкретные лимиты нужно фиксировать для скачанной
сборки, а не переносить между поставками.

### Community License

[Получение](https://1c-dn.com/1c_enterprise/get_community_license/),
[FAQ](https://1c-dn.com/1c_enterprise/frequently_asked_questions/),
[описание назначения](https://1c-dn.com/developer_tools/1_enterprise_platform_community_license/).

Бесплатная лицензия предназначена для разработки и отладки, не для реального
управления/учёта. Требуются регистрация и подтверждение телефона; на странице
получения описан серверный сеанс разработчика. Это потенциально более полезный
стенд для клиент-серверных опытов, чем учебная версия. Точные условия,
применимость к исследовательским опытам и доступность дистрибутива проверяются
при получении лицензии. Аккаунт в рамках шага 0 не создавался.

Важное расхождение официальных страниц: страница получения называет минимальные
сборки **8.3.24.1528 / 8.3.25.1257**, FAQ говорит о дистрибутивах **8.3.23+**.
Не превращаем это в обобщённую гарантию «любая 8.3.23 подойдёт»; выбираем
подтверждённую поставку и записываем реально активированную сборку.

### Другие пути

- Коллега с законным стендом выполняет наш минимальный сценарий и отдаёт
  воспроизводимый результат, версию и искусственную конфигурацию. Ему не нужно
  передавать нам рабочую базу, ключи или клиентские данные.
- Публичная веб-демонстрация полезна для UX и последовательности действий;
  не даёт полный контроль над версией, транзакциями и окружением. Конкретная
  доступная сегодня демобаза в этом исследовании не квалифицирована.
- Учебные видео и официальные курсы дают кадры и сценарии, но не наблюдаемую
  спецификацию событий. Запрашивать у авторов отдельные записи нужных сценариев.
- EDT полезен как среда просмотра/редактирования; его наличие само по себе не
  заменяет рантайм платформы и не даёт права распространять её файлы.

| Форматы контейнеров и БД | tool1cd, v8unpack, onec_dtools | Независимые читатели/распаковщики. Поддержка форматов ограничена версиями |
| Интеграционные клиенты | OData, HTTP/SOAP, Native API, DAP-адаптеры | Поверхность интеграций; нужен установленный оригинал для проверки поведения |
| Прикладные библиотеки | БСП/SSL, oscript-library, tools_ui_1c | Карта востребованного API. БСП — прикладной слой, не часть вновь выбранного scope |
| Практика сообщества | Infostart, Mista, курсы, конференции, книги | Рецепты, ошибки, ожидания пользователей; проверять по первичным источникам и опытам |
| Данные эксплуатации | Технологический журнал, SQL-трассы, планы запросов | Позже помогут понять транзакции и запросы; лог конкретного backend не универсальная семантика |

Нельзя из факта публичного GitHub делать вывод, что чужие конфигурации,
поставляемые XSD, тексты справки, картинки и двоичные файлы можно включать под
BSD-3-Clause. В данном шаге оставлены ссылки и собственные описания.
