# Поддерживаемое подмножество BSL (P07)

Реализация — `internal/bsl` (лексер и разбор вручную), команда `oddyness bsl check <файл>`.
Это список того, что парсер **принимает**; всё остальное — явная ошибка с позицией
(`строка:колонка: сообщение`), а не молчаливый пропуск. Принятие синтаксиса не означает
исполнения: VM появится в P08, а совместимость с оригиналом этим списком не заявляется
(ожидания — наши тесты, оригинал не запускался).

## Решение о парсере

Рассмотрен MIT-кандидат LazarenkoA/1c-language-parser (Yacc, числовой литерал через
`strconv.ParseFloat` — потеря цифр необратима, см. `03-reuse.md`). Для подмножества P07
выбран **собственный рекурсивный разбор**: числа сразу становятся точными `value.Number`
(P03), нет генерируемой грамматики и зависимости, позиции и сообщения под контролем.
Переход на Yacc-грамматику возможен позже, если подмножество вырастет; тогда числовые
лексемы обязаны остаться текстовыми.

## Принимается

- Русские и английские ключевые слова, регистр не важен: `Процедура/Procedure`,
  `КонецПроцедуры/EndProcedure`, `Функция/Function`, `КонецФункции/EndFunction`,
  `Перем/Var`, `Возврат/Return`, `Знач/Val`, `Экспорт/Export`, `Истина/True`, `Ложь/False`,
  `Неопределено/Undefined`, `Null`, `И/And`, `Или/Or`, `Не/Not`.
- Переменные модуля (`Перем а, б Экспорт;`) и локальные переменные в начале подпрограммы.
- Процедуры и функции с параметрами (`Знач`), `Экспорт`.
- Операторы: присваивание `имя = выражение;`, вызов `имя(аргументы);`, `Возврат [выражение];`;
  последний оператор перед `КонецПроцедуры`/`КонецФункции` может быть без `;`, пустые операторы допустимы.
- Выражения: числа (точные, до 32 значащих цифр), строки `"..."` с `""` и продолжением
  строки через `|`, `Истина/Ложь/Неопределено/Null`, имена, вызовы, скобки, унарные `+ -`,
  `* / %`, `+ -`, сравнения `= <> < > <= >=` (без цепочек), `Не`, `И`, `Или`.
- Комментарии `//`; BOM в начале файла (в `bsl check`); колонки считаются в символах.
- Проверки разбора: `Возврат` со значением только в функции, без значения — только в
  процедуре; повтор имени подпрограммы, параметра или переменной в одном объявлении;
  `Перем` после операторов; зарезервированное слово в роли имени.

## Явно не поддерживается (ошибка «is not supported»)

Директивы компиляции `&…` и инструкции препроцессора `#…`; операторы `Если`, `Пока`, `Для`,
`Попытка`, `ВызватьИсключение`, `Перейти`, `Прервать`, `Продолжить`, `Выполнить`, `Новый`
(управление потоком — P09); литералы дат `'…'`; доступ к свойствам и индексы (`а.б`, `а[1]`);
тернарный `?`; значения параметров по умолчанию; пропущенные аргументы вызова; операторы на
уровне модуля вне подпрограмм.

## Не проверено

Приоритеты операций и правила продолжения строк соответствуют общему описанию языка, но не
сверялись с оригиналом; список зарезервированных слов неполон (только перечисленные выше).

## Исполнение (P08, `internal/vm`, `oddyness bsl run <файл> <функция> [аргументы]`)

Модуль компилируется в байткод со слотами; ошибки компиляции и выполнения имеют позицию.
Аргументы командной строки, записанные как точное число, передаются числом, остальные — строкой.

- Значения: Число (`value.Number`), Строка, Булево, `Неопределено`, `Null`. Локальная
  переменная без значения — `Неопределено`; функция без `Возврат` возвращает `Неопределено`.
- Операции: `+` (числа или две строки), `-`, унарные `+ -`, сравнения (`=`/`<>` для разных типов
  дают `Ложь`/`Истина` без ошибки; порядок `< > <= >=` — только Число с Число и Строка со
  Строкой, строки по байтам UTF-8, не по правилам культуры), `Не`/`И`/`Или` только над булевыми,
  `И`/`Или` вычисляют правую часть лениво.
- Ошибки типов, переполнение 32 цифр, превышение числа инструкций (по умолчанию 10 000 000),
  глубины вызовов (256) и отмена контекста — явные ошибки времени выполнения.
- Не поддерживается и отклоняется при компиляции: `*`, `/`, `%` (правила точного умножения и
  деления не определены, см. `numbers.md`), переменные уровня модуля, присваивание параметру,
  объявленному без `Знач` (в оригинале это передача по ссылке), неизвестное имя или
  подпрограмма, неверное число аргументов, процедура в выражении.
- Не проверено на оригинале: преобразования между типами (в оригинале часть из них не ошибка),
  порядок вычисления аргументов, поведение `Null` в операциях.
