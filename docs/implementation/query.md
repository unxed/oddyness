# Минимальный язык запросов (P17)

Реализация — `internal/query`. Часть 1: разбор и проверка по метаданным в типизированное промежуточное
представление. Исполнение над остатками регистра — часть 2.

## Язык

```
ВЫБРАТЬ Товар, Количество КАК Остаток
ИЗ РегистрНакопления.Запасы.Остатки
ГДЕ Товар = &Товар И (Количество > 0 ИЛИ НЕ Количество <= -1.5)
УПОРЯДОЧИТЬ ПО Остаток УБЫВ
```

- Свой лексер и рекурсивный разбор вручную; грамматика 1С или SQL не заимствована. Ключевые слова — русские и
  английские (`SELECT FROM WHERE AND OR NOT ORDER BY AS ASC DESC TRUE FALSE`, `AccumulationRegister.<имя>.Balance`),
  регистр букв не важен. Зарезервированные слова нельзя использовать как имена полей.
- Единственный источник — виртуальная таблица остатков регистра накопления `РегистрНакопления.<имя>.Остатки`
  (имя или `id` регистра); поля — измерения и ресурсы по имени или `id`.
- `ГДЕ`: `И`, `ИЛИ`, `НЕ`, скобки, сравнения `= <> < <= > >=` поля с полем, параметром или литералом. Литералы:
  число (точный `value.Number`, без float), строка в `"…"` (кавычка удваивается; одна строка), `Истина`, `Ложь`.
  Для булева и ссылки допустимы только `=` и `<>`. Литерала даты нет — дата передаётся параметром.
- Параметр `&Имя` (без учёта регистра); его тип выводится из сравнения с полем; два разных типа — ошибка.
  Значения передаются отдельно (`Query.Bind`) и в текст не подставляются: число — только `value.Number`,
  строка, дата `ГГГГ-ММ-ДД`, булево, `value.Ref` нужного справочника (`nil` — пустая ссылка).
- `УПОРЯДОЧИТЬ ПО`: столбцы результата (по псевдониму или имени поля), `ВОЗР`/`УБЫВ`.

## Диагностика

Первая ошибка возвращается как `*query.Error` с позицией `строка:колонка` (в символах) и признаком
`Unsupported`. Не поддерживается явной ошибкой, а не молчанием: `*`, соединения, группировка, `ИМЕЮЩИЕ`,
`ОБЪЕДИНИТЬ`, `РАЗЛИЧНЫЕ`, `ПЕРВЫЕ`, `В`, `ПОДОБНО`, `МЕЖДУ`, `ВЫБОР`, `NULL`, вызовы функций, арифметика,
составные имена, другие источники (справочники, документы), виртуальные таблицы `Обороты`/`ОстаткиИОбороты`,
сравнение двух констант или двух параметров.

## Без сырого SQL

Результат разбора — структуры `Query`, `Cmp`, `FieldRef`… с идентификаторами из метаданных; текст запроса в SQL
не превращается. Исполнение (часть 2) идёт над `Store.Balances`/`Movements`; суммы и сравнения — точным
`value.Number` в ядре (решение `storage.md`, SQL-агрегаты по числам запрещены). Метасимволы SQL в идентификаторе —
ошибка лексера/проверки, в строковом литерале — данные.

## Не входит

Полная SDBL, компоновка данных, все виды соединений, остатки на дату, неявное заимствование GPL-грамматики.
